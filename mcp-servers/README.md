# MCP Servers

This directory contains example and bundled MCP server integrations for Pyntra.

## Contents
- `reverse_shell/`: Python-based reverse-shell bridge examples
- `pent_claude_agent/`: external-agent bridge examples

## Usage Notes
1. Review each server directory for configuration details.
2. Store secrets in environment variables or private config files.
3. Enable only the servers required for your deployment.
