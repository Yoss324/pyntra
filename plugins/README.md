## Plugins

This directory contains optional plugins/extensions that integrate Pyntra with other tools.

- `burp-suite/`: Burp Suite extensions

### Burp Suite Extension
- **Path**: `plugins/burp-suite/pyntra-burp-extension/`

  - **Build output**: `plugins/burp-suite/pyntra-burp-extension/dist/pyntra-burp-extension.jar`
- **Docs**: see the plugin folder `README.md`
