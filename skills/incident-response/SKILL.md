# Incident Response

## Overview
Use this skill to support detection, triage, containment, evidence preservation, communications, and recovery during active or recent security incidents.

## Recommended Workflow
1. Confirm scope, targets, constraints, and evidence requirements before testing.
2. Map likely attack surfaces for Incident Response and prioritize the highest-value validation paths.
3. Execute focused tests safely, capture reproducible evidence, and avoid unnecessary impact.
4. Summarize findings in English with impact, confidence, reproduction notes, and remediation guidance.

## Typical Checks
- Scope and timeline establishment
- Containment and eradication planning
- Evidence handling and chain-of-custody needs
- Recovery sequencing and lessons learned

## Useful Tools
- Endpoint and network telemetry
- SIEM or log platforms
- Case management systems
- Forensics and timeline analysis utilities

## Output Expectations
Produce an English assessment that records scope, assumptions, steps performed, evidence, impact, and remediation.
